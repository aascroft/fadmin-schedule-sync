How to use this tool
Show step-by-step instructions

Part 1 — Export the FAdmin file

  1. Go to FAdmin and open the side menu. Select System, then select Custom Actions.
    https://fadmin.flippback.com/custom_actions
  2. Under Action Type, enter Merchandising Campaign Identifier.
  3. Set Start Date to today's date.
  4. Set End Date to the end of your desired range. This is typically one year out, or further if the range ends in December.
  5. Submit the export request.
  6. The file will be sent to the email address associated with your FAdmin account within 15 minutes.
  7. If the export does not arrive, submit the request again.

Part 2 — Export the context file from ClickUp

  1. Open the PS Retailer Hub list in ClickUp:
    https://app.clickup.com/9003147350/v/l/6-901702655628-1
  2. Make sure all statuses are expanded in the view.
  3. Click the settings cog in the top-right of the list.
  4. Select Export view.
  5. Toggle on All Columns.
  6. Confirm the format is set to CSV.
  7. Click Download.

Part 3 — Export the dedupe file from ClickUp

This file contains all existing PS tasks and is used to avoid creating duplicate entries.

  1. Open the Processing Support Board list in ClickUp:
    https://app.clickup.com/9003147350/v/l/6-901702638190-1
  2. Make sure all statuses are expanded in the view.
  3. Click the settings cog in the top-right of the list.
  4. Select Export view.
  5. Toggle on All Columns.
  6. Confirm the format is set to CSV.
  7. Click Download.

Part 4 — Run the tool

  1. Select Processing Support at the top of this page.
  2. Upload each of your three CSV files into the correct upload zones.
  3. Click Generate CSV.
  4. Review the status summary — it will show how many rows are ready to import, how many were skipped as duplicates, and any warnings.
  5. Click Download Import File to save the output to your computer.
